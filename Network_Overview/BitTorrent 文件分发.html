⚠ 教学简化说明（以下均为「此处为简化演示」）

  • Tracker 采用 HTTP announce；未涉及 UDP Tracker、DHT、PEX 与加密握手（PE/MSE）。
  • 一个 piece 用一次 request/piece 传输；真实协议中 piece 由多个 16 KiB 的 block 请求组成。
  • TCP 三次握手（SYN / SYN-ACK / ACK）被压缩为一次“连接建立”事件。
  • 时序参数（约 10s 的 unchoke 周期、约 30s 的乐观解除阻塞周期、announce interval）已压缩。
  • 文件固定为 8 × 256 KiB 分片，拓扑固定为全连接；真实场景由分片大小参数与发现机制决定。
  • peer_id、IP、SHA-1 等均为演示用的示例值，仅用于展示字段结构。
