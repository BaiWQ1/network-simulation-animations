⚠️ 简化演示说明（点击展开）
  • 未展示 DNS 解析、ARP 等前置步骤，假定域名已解析为 IP。
  • 使用明文 HTTP 以便观察报文首部；实际网站普遍使用 HTTPS（TLS 加密后首部不可见）。
  • TCP 初始序号 ISN 简化为固定值 0（实际为随机数）；窗口大小、MSS 等字段省略。
  • HTTP 首部字段为典型示例值，并非真实浏览器抓包结果。
  • Cookie 属性仅演示 Path 与 HttpOnly；Expires / Max-Age / Secure / SameSite 未展示。
  • 未演示 TCP 连接释放（FIN 四次挥手）；keep-alive 下连接将被复用。
