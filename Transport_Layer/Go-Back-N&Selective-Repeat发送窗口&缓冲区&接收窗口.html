教学简化说明

  • 序列号空间简化为 0～7，未完整演示序列号回绕与模运算。
  • ACK 含义约定为：ACK n 表示序号 n 已按序正确接收，期望下一个分组为 n + 1。
  • GBN 接收窗口固定为 1；SR 接收窗口简化为 4。
  • 定时器被简化：GBN 表现为发送窗口 base 分组超时后重传全部未确认分组；SR 表现为每个未确认分组独立超时，仅重传对应分组。
  • RTT、拥塞控制、校验和、链路差错等细节未纳入本演示。
