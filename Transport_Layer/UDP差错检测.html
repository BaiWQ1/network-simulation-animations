教学正确性与简化说明

  1. 逐字运算：发送方 14 个 16 位字逐字累加（每字一步），进位回卷实时标出；所有中间值由脚本按反码加法规则计算生成，可手工复核。
  2. 链路简化：页面以“直连链路”表示传输路径，省略 IP 层封装、路由与 ARP 等细节（此处为简化演示）。
  3. 0x0000 的语义：在 IPv4 中，UDP 校验和字段为 0x0000 表示“发送方未计算校验和”。本例计算结果为 0x6507，不涉及该歧义；计算过程中“暂置 0”仅是占位。
  4. 对比演示：“1 位错误”为假想场景（此处为简化演示）；真实传输中的比特错误是随机的。UDP 只检错、不纠错、无重传。
  5. 填充规则：若数据为奇数字节，需补 0 凑齐 16 位字参与计算（补的 0 不发送，RFC 768）。本例数据为 8 字节，无需填充。
  6. 检错能力（教材常用结论）：可检出所有单比特与奇数位错误、所有长度小于 16 位的突发错误；随机错误漏检概率约 2⁻¹⁶ 量级。IPv6 中 UDP 校验和必须启用（RFC 8200）。
